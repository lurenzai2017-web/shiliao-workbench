史料研析台 v0.1.0 未簽名測試版

一、啟動

macOS：解壓後打開「Historical Evidence Workbench.app」。如果系統阻止首次啟動，請按住 Control 點擊應用程式，選擇「打開」，再確認一次。

Windows：解壓後運行「Historical Evidence Workbench.exe」。如果 SmartScreen 顯示提醒，請先確認文件來自本項目的 GitHub Release，再選擇「更多資訊」和「仍要運行」。

二、開始研究

1. 上傳自己的 TXT、Markdown、CSV、JSONL 或 JSON 史料。
2. 以自然語言輸入研究需求。
3. 選擇模型供應商，填寫自己的 API 地址、模型名稱與 API Key。
4. 測試連接、生成研究規約、估算 Token，然後試跑樣本。
5. 確認規約後進行完整判讀，最後複核並匯出項目包。

三、資料與網絡

- 本版本不包含或連接任何私人文獻庫。
- API Key 不會寫入研究結果；請勿把自己的 Key 分享給其他人。
- 史料片段會傳送給您自行選擇的模型供應商，使用前請確認其隱私政策。
- Prompt、斷點與本機加密保存的 Key 只留在目前電腦的應用程式資料目錄。
- 程式介面由本機回環地址提供；除了您配置的模型接口，不需要連接本項目的遠端服務。

四、測試版提醒

這是未簽名測試版本。請先用非機密、可重複驗證的小型材料試用；重要研究結果仍應回到原文人工核查。

# 小型功能測試材料（非真實史料）

> 說明：以下文字僅為測試史料研析台功能而仿作，不是真實史料，不可作為學術引文。

紹熙五年，臺諫言某甲與某乙久相交遊，又數薦其門生入仕，遂指二人陰結朋黨，請加罷黜。某甲上疏辨曰：「臣與乙雖有文字往還，未嘗相約營私；今以交遊為黨，恐塞天下士人相知之路。」詔令有司詳核。

某郡鄉民修築堤防，各率鄉黨相助，旬日而工畢。郡守嘉其同心，賜酒勞之。此處「鄉黨」僅指同鄉居民，未涉及政治結社或官員進退。

其後言官再論某乙，稱其「引所親居要職，排異己於外」，但奏章沒有列出受薦者姓名。是否能據此判為朋黨材料，仍須結合前後文並標記待核。

另有書目一條，只記《辨朋黨札子》卷次、頁碼與校勘說明，沒有札子正文。此條應排除，不得依題名推測內容。

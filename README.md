# 史料研析台（公開版）

面向歷史研究者的互動式 AI 史料工作流：上傳研究材料，以自然語言說明需求，生成可修改的研究規約，試跑樣本，再進行可續跑的批量判讀與人工複核。

這個公開版不包含任何私人文獻庫的網址、密碼、檢索接口或測試程式。使用者只分析自己上傳的材料，並自行配置模型服務。

## 主要功能

- 上傳 TXT、Markdown、CSV、JSONL 與 JSON；單個文字檔建議小於 8 MB
- 支援 OpenAI、DeepSeek、通義千問、Kimi、MiMo、Ollama 及 OpenAI 相容接口
- 自然語言需求轉換為可人工修改的研究規約
- 工作前估算 Token 與成本範圍
- 自適應樣本試跑，遇到超時會縮小批次重試
- 批量完整判讀與本機斷點續跑
- 高／中／低相關度、採用／待核／排除與批量複核
- 保存、匯入與匯出 Prompt 模板
- 依篩選範圍匯出 Markdown，或匯出可離線閱讀的項目包
